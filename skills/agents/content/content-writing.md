**Category:** skills/agents/content

## Purpose

Write high-quality content for YouTube, blogs, social media, and documentation.
Covers long-form articles, video scripts, short-form copy, and technical writing.

---

## Content Types

### YouTube Scripts (Mindivo)
- Niche: Dark psychology, influence, manipulation, mindset
- Tone: Mysterious, authoritative, slightly dramatic
- Format: Hook → Story → Insight → Takeaway → CTA
- Length: 8–12 min (1200–1800 words)
- TTS-optimized: short sentences, natural pauses

### Blog / Articles
- SEO-optimized structure (H1, H2, H3)
- Intro hook → problem → solution → conclusion
- Internal linking suggestions
- Target: 1000–2500 words

### Social Media
- Twitter/X: Thread format, punchy, no filler
- LinkedIn: Professional, story-driven
- Instagram captions: Short, emoji-sparse, CTA

### Technical Docs
- README files for GitHub repos
- API documentation
- Setup guides and tutorials

---

## Writing Rules (Axiom Standard)

1. Never start with "In today's world" or "In conclusion"
2. Use active voice >80% of the time
3. Short paragraphs (2–3 sentences max for scripts)
4. Every section answers: So what? Why does this matter?
5. CTAs are specific: "Comment X below" not "engage with us"

---

## Dark Psychology Content Guidelines (Mindivo)

- Frame as education, not instruction
- Add ethical disclaimers naturally in the script
- Use real psychological research as backing
- Topics: cognitive biases, persuasion, manipulation tactics, body language, power dynamics
